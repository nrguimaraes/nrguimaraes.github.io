About the Prompt Template Generator

Define a prompt with variables such as {audience} or {tone}. Generate every combination from manually supplied values, or upload a CSV with one prompt per row. Results can be copied or exported as TXT and CSV. The tool does not upload the input to any server.

The tool is intended for educational use. Avoid using personal, confidential, or sensitive data when preparing examples.
