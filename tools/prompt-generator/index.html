Gerador de Templates de Prompts

Crie um template com variáveis, defina vários valores para cada uma e gere automaticamente todas as combinações possíveis. Tudo é processado localmente no navegador.

1. Escreva o template

Utilize chavetas para identificar variáveis, por exemplo: {tom}, {assunto} ou {destinatario}.

2. Defina os valores

Clique em Detetar variáveis para começar.

Cada coluna deve ter o nome de uma variável do template. Cada linha corresponde a um prompt a gerar. São aceites ficheiros separados por vírgulas, ponto e vírgula ou tabulações.
